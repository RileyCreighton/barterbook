# A three-minute BarterBook demo

The pitch video is optional under the official rules, with a three-minute maximum. This outline aims for 2:40. Use the real browser basket and three-person receipts already recorded in [the evidence guide](browser-execution-evidence.md).

| Time | Show and explain |
|---|---|
| 0:00–0:20 | Market and product name. “Sometimes you want a whole package, not a single swap. BarterBook connects selected inventory, exact baskets and three-person matches.” |
| 0:20–0:55 | Recorded two-for-one basket. Show Alice's 10 A + 5 B and Bob's 20 C, then the net receipts after token fees. |
| 0:55–1:25 | The actual finalized basket receipt and Explorer link. Explain that both wallets approved one transaction and every token leg settled together. |
| 1:25–2:00 | The recorded three-way match: Alice → Bob → Carol → Alice. Open its actual finalized receipt: 9.9 A, 19.8 B, 29.7 C delivered. |
| 2:00–2:25 | Try the demo. Show the test-token faucet and two-/three-profile testing instructions. “You can execute the same flow with your own Phantom Devnet wallets.” |
| 2:25–2:40 | GitHub and evidence downloads. “Wallets keep control, each approval covers exact terms, and the outcome is independently verifiable.” |

Keep “Solana Devnet · test tokens” visible. Use clear cuts to shorten navigation; do not imply a cut is continuous execution. Existing receipts are genuine recordings, and the walkthrough explains them without initiating another transaction. Never show recovery phrases, private keys, cookies or RPC credentials.

A technical video, if useful and time permits, may run up to five minutes: show the shared transaction builder/verifier, immutable signing journal, recovery checks, exact receipt validation and selected regression tests. It is optional too.
